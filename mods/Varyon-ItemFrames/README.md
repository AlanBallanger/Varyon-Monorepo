# Varyon-ItemFrames

Adds Item Frames to the Varyon server. They can be placed on walls and let players
insert or remove an item by interacting with the frame while holding an item or
with an empty hand.

Craft them at the Furniture Bench with 2 Tree Trunk + 1 Tree Sap. The Bamboo
variant uses Bamboo Trunk, the Light Temple variant uses Marble.

Variants: default, Ancient, Bamboo, Kweebec, Light Temple, Lumberjack, Tavern.
